# 项目 / 论文 / 工作区：新方案（2026-10-10）

对应 `ui-fixes-todo.md` 第 6、7 项。

## 现在的问题

左侧有四个视图都和"项目"有关：论文库、对话（按项目分组）、项目、工作区文件。
它们各自改各自的状态，结果是选了项目，中间的论文、右侧对话、文件树不一定跟着变。

第 6 项（切换项目或对话时中间论文不跟着变）已在 `5a7bf75` 修掉：
`store.selectProject` 成为切换项目的唯一入口，项目列表、标题栏切换器、命令面板、打开对话都走它，
它会把该项目的论文带到中间（已打开的标签优先）。

## 方案：一个"当前项目"驱动一切，左侧像 Codex 桌面版那样列项目

1. **合并"对话"和"项目"两个视图为一个"项目"视图**（活动栏只留一个入口）。
   - 每个项目一行，可展开/折叠；展开后先列它的论文，再列它的对话，最后是"＋ 新对话"。
   - 顺序：研究项目在上；论文工作区按最近活动排序；"通用"（不属于项目的对话）在最下面。
   - 点项目行 = `selectProject`：中间换成它的论文，工作区文件树、源代码管理、终端、新对话都切到它。
   - 点项目下的论文 = 打开那篇论文；点对话 = 在右侧打开那个对话，并切到它的项目。
   - 当前项目高亮并自动展开；其他项目默认折叠，只显示未读/待批准的小圆点。
   - 收件箱（铃铛）保持不变。
2. **论文库只负责"收集"**：导入、搜索、删除。点论文 = 打开它并切到它的工作区（现有行为）。
3. **工作区、源代码管理、终端**不再有自己的项目选择，一律跟随当前项目（标题栏显示当前项目名）。
4. 项目详情（路径、关联论文增删、运行记录）放进项目行的"…"菜单，不再占一整个视图。

不改后端：每篇论文一个工作区、研究项目可关联多篇论文，这些规格（`glossx-workspaces.md`）保持不变。
