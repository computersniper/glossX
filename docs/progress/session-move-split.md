# 可拖动工作区分区与移动会话（2026-10-11）

基线 `b22d585`，备份分支 `backup/session-move-split-20261011`。修改前 fetch 确认与远端一致，工作区干净。

## 已完成

- 项目列表与工作区设置之间增加可拖动水平分隔线。支持鼠标、触摸/触控笔 Pointer Events、键盘上下键及 Home/End；使用 pointer capture，取消事件释放拖动状态。比例保存在 `glossx.projects.split`，刷新后仍保留，上下区最小高度保护。
- 去掉旧 `.wb-list-compact` 对项目列表施加的 40% 最大高度；真实 UI 验证发现该限制会让拖动比例变化而实际尺寸不变。
- 对话列表更多菜单增加“移动到项目…”：选择活动研究项目、方向项目、论文工作区或“通用”。运行中/等待交互的会话不能移动。归档对话可以移动，归档状态保留，目标项目必须可用。
- `POST /api/sessions/{id}/project`，必填 `project_id`（null 表示通用）；后端校验目标和运行/工作区迁移状态。会话 id、消息和附件保留，后续使用目标工作目录和当前分支；旧文件、历史 Git 和已完成运行仍在原工作区。
- 目标项目论文加到原有论文范围中，既有讨论来源不会丢失。清理 provider_thread，新增明确工作区边界的系统记录，CLI 下一次调用不续接旧工作区会话。
- 当前打开的对话移动后同步所选项目，刷新分组及收件箱。移动不改变工作目录内的任何文件；跨移动边界的“回退并恢复文件”明确拒绝，避免误用新工作区历史。
