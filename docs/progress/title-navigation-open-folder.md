# 居中搜索、访问历史与打开文件夹

日期：2026-10-11。基线 `ba2ec9e`，修改前备份 `backup/center-search-nav-20261011`。

## 已实现

- 顶部改为左右等宽、中间搜索的布局，搜索框左侧增加返回/前进箭头。保留原命令搜索功能，小屏收缩为图标入口。
- `TitleNavigation` 记录本窗口内最多 100 次标签页/agent 会话访问；返回/前进不会追加历史；返回后打开新页面会清除前进分支。关闭的标签页、已归档/删除且不在列表中的会话会跳过；刷新不保留访问历史。
- “打开文件夹…”入口：文件菜单、命令面板、项目栏；欢迎页“打开工作区”也改为此操作。
- Electron 通过受限 IPC 打开原生目录选择器；仅主应用窗口可调用。旧桌面壳和普通网页没有该方法时，使用路径输入，明确是运行 GlossX 的电脑上的路径。
- `POST /api/agent/projects/open-folder`，请求 `{path: absolute_path}`。直接挂接已有文件夹，不复制文件；同目录复用活动项目，归档项目提示先恢复，已移除项目可通过显式打开文件夹重新建立项目。
- 复用路径安全规则：已有目录、禁止文件系统根/应用数据/CLI 配置、禁止与其他工作区嵌套。
- 新挂接目录写入正常 `.glossx` 工作区配置，但打开/读取 Git 状态不会初始化仓库或提交文件；已有 Git 的 HEAD 和暂存修改保留。显式版本控制操作或创建 agent 会话仍沿用现有 Git 初始化机制。
- 打开后选中对应项目、退出原活动会话并显示文件树，后续新对话使用该项目目录。
